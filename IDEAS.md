# Ideas & Future Roadmap

## Cross-Device Sync with Accounts
**Status:** Backlog
**Priority:** Medium

Turn the app into a cloud-synced multi-device platform:
- **Backend**: Firebase (Auth + Firestore) — free tier, no server management
- **Mobile**: PWA (same web code, mobile-responsive)
- **Desktop**: Refactor to use Firestore instead of localStorage
- **Features**: User accounts (login/signup), real-time sync between devices
